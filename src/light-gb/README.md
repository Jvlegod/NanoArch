## controls

### keyboards

| keyboard Key | Function | Description |
| --- | --- | --- |
| up, down, left, right | D-Pad | Move character / Menu navigation |
| Z | A | Confirm |
| X | B | Back |
| Enter | Start | Start |
| Backspace | Select | Select |
| Space | Turbo | Hold for 3x speed |
| R | Reset | Soft reset the game |
| P | Palette | Cycle color palettes |
| Esc | Quit | Auto-save and exit program |
